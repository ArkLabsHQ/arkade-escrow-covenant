# Escrow

A page that builds an Arkade escrow and spends it. Paste an Arkade.Money address for the buyer and the seller. A simulated oracle in the browser signs the release that pays the seller.

The unilateral exit is a seconds CSV, a multiple of 512 and at least the operator's unilateral exit delay. Mutinynet's delay is 2048 seconds.

GitHub Pages publishes the `site` directory from `master`. After this workflow is on `master`, set the repository Pages source to GitHub Actions. The site is then at https://tiero.github.io/escrow-arkade/.
