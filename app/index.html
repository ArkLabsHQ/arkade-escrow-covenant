Escrow

    Refund pays the buyer once the emulator clock passes this time.

    Those four fields are locked into the taproot. Paste the same buyer, seller, amount, and refund time that created the address. If you saved the file from that browser, restore it under Advanced and the fields fill in.

    Wallet:

    Save this file before you leave. It holds the parameters and the oracle key. Another browser can see the coins, and it cannot release or refund without the file.

    Advanced

    A multiple of 512, at least this operator’s exit delay. The seconds start when the funding transaction is mined. Unroll that transaction first.

    A seller mnemonic is the 12 or 24 words from Arkade.Money. On mutinynet those words use the testnet BIP86 key. An nsec or 64-character hex key works too. Either field can be left blank.
